# AlphaGenomeWorkshop

This repository contains a modified jupyter notebook for Google DeepMind AlphaGenome API. Use subjected to AlphaGenome API terms of service - please see the corresponding pdf document in the repository.


# Running locally

To install a local copy of alphagenome, clone a local copy of the repository:

```bash
git clone https://github.com/google-deepmind/alphagenome.git
```
In the case of miniconda, installation would be achieved with the following:

```bash
conda create -n alphagenome-env python=3.11
conda activate alphagenome-env
pip install -e ./alphagenome
```
